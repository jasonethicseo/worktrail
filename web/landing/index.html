새 세션의 첫 순간

과거를 다시 읽는 대신, 멈춘 자리에서 이어 갑니다

코드와 커밋에는 무엇을 바꿨는지만 남습니다. 왜 그렇게 정했는지, 무엇이 아직 안 풀렸는지, 다음이 누구 차례인지는 남지 않습니다.

보통의 AI 세션

새 세션은 지난 세션을 모릅니다

  1. 코드, diff, 커밋 메시지를 다시 읽습니다.
  2. 지난번에 무엇을 정했고 왜 그랬는지 거기서 짐작합니다.
  3. 이미 버린 방법을 다시 꺼내거나, 끝난 일을 또 할 수 있습니다.
  4. 사람이 지난 대화를 요약해 다시 붙여 넣습니다.

세션이 바뀔 때마다 같은 해석을 처음부터 되풀이합니다.

Worktrail로 이어 갈 때

새 세션이 지금 유효한 상태를 먼저 받습니다

  1. Claude Code는 세션을 시작할 때 이 작업폴더에서 무엇을 하던 중이었는지를 먼저 띄웁니다. 스레드의 초점, 안 풀린 것, 다음 행동.
  2. 거기서 이어 가려면 resume 한 번. 제약과 결정, 근거가 된 원문, 지금 git 위치까지 일곱 칸이 옵니다.
  3. 결정에는 이유와 누가 정했는지가, 결론에는 근거가 된 원문이 붙어 있습니다.
  4. 다음 행동에서 바로 시작하고, 새로 알게 된 것은 그 자리에 다시 남깁니다.

해석이 끝난 상태가 넘어오므로, 새 세션은 거기서 출발합니다.

무엇이 남는가

기억이 아니라, 지금 유효한 작업 상태

일은 스레드 단위로 남습니다. 한 저장소에서 하나의 질문이나 변경을 끝까지 따라가는 단위입니다. 새 세션이 resume으로 받는 것은 아래의 일곱 칸입니다.

초점focus

이 스레드가 무엇을 위한 것이고, 무엇이 되면 끝나는지.

제약constraints

앞으로 지켜야 할 선. 저장소 전체에 걸리는 것은 그 저장소의 모든 스레드에 같이 나옵니다. 외부 결제 호출을 사용자 요청 안에서 기다리지 않는다

결정decisions

따르기로 한 선택과 그 이유, 사람이 정했는지 에이전트가 정했는지. 옛 결정은 지워지지 않고 새 결정으로 대체됩니다. 결제 대행사는 페이레일로 간다 · 부분취소와 정산 주기가 갈랐다

열린 문제open

아직 안 풀린 질문과 막힌 것.

다음 행동next

다음에 할 일과 그 차례가 누구인지. 사람, 에이전트, 또는 지켜보기만 할 때. 에이전트는 단계마다 이것을 다시 말해야 합니다.

근거evidence

기계나 사람이 실제로 말한 것. 시험 결과, 에러, diff를 요약하지 않고 원문 그대로 두고 번호로 답니다.

현재 위치anchor

이 작업폴더의 브랜치·HEAD·바뀐 파일, 그리고 스레드에 붙은 커밋.

남기지 않는 것

  • 대화 전체. 기록되는 것은 에이전트가 도구로 남긴 것과, 훅이 붙이는 커밋·작업폴더 위치뿐입니다.
  • 에이전트의 추측. 뒤집힐 수 있는 가설은 노트에 머물고, resume에는 나오지 않습니다.
  • 코드 자체. 코드는 git에 있습니다. Worktrail은 코드 주변의 맥락을 남깁니다.

규칙은 서버가 지킵니다

  • 주제 없이는 스레드를 열 수 없습니다.
  • 다음 행동과 그 차례를 적지 않으면 단계를 남길 수 없습니다.
  • 모든 글의 첫 줄은 제목이고, 120칸을 넘으면 거절됩니다.

무엇이 열려 있고, 다음은 누구 차례인가

열린 스레드마다 에이전트가 마지막으로 선언한 다음 행동과 그 차례가 한 줄로 보입니다. 사람이 움직일 것, 에이전트에게 넘긴 것, 아직 아무도 정하지 않은 것이 나뉩니다. 옆의 Now 띠에는 최근 기록이 방향(결정·제약·선언)과 흔적(노트·증거·커밋)으로 나뉘어 쌓입니다.

Claude Code

이 컴퓨터에만

플러그인 두 줄이면 MCP 등록과 세션 훅까지 끝납니다. 신청은 필요 없고, Python 3.11 이상 또는 uv가 있으면 됩니다.

/plugin marketplace add jasonethicseo/worktrail
/plugin install worktrail@worktrail

Claude Code 안에서 실행합니다. 새 버전을 자동으로 받으려면 auto-update를 켭니다. 설치 안내 →

서버에

신청 화면에서 서버를 고르면 설치 한 줄을 받습니다. 그 줄이 클라이언트 설치, MCP 등록, 훅까지 한 번에 합니다.

curl -fsSL <받은 URL>/install.sh | sh -s -- --server

URL이 곧 열쇠입니다. 화면 공유나 채팅에 올리지 않습니다.

세션을 시작하면 이 작업폴더의 열린 스레드가 저절로 뜹니다. 커밋도 저절로 붙습니다.

Codex CLI

이 컴퓨터에만

플러그인이 없으므로 소스에서 깔고 직접 등록합니다. 신청은 필요 없습니다.

git clone https://github.com/jasonethicseo/worktrail.git && cd worktrail
python3 -m venv .venv && .venv/bin/pip install -e ".[mcp]"
mkdir -p ~/.casebook && echo local > ~/.casebook/mode
codex mcp add casebook -- $PWD/.venv/bin/python -m casebook.adapters.mcp_proxy

기록은 ~/.casebook/casebook.db에 남습니다. 자리를 옮기려면 CASEBOOK_DB를 줍니다.

서버에

같은 설치 한 줄입니다. codex가 깔려 있으면 알아서 등록하고, 첫 연결이 끊기지 않게 Codex의 시작 대기를 30초로 올립니다.

curl -fsSL <받은 URL>/install.sh | sh -s -- --server

Claude Code와 Codex가 둘 다 있으면 한 줄로 둘 다 등록됩니다.

Codex에는 세션 훅이 없습니다. 세션을 열고 한 번 casebook 열린 스레드 보여줘라고 하면 그 세션 내내 알아서 기록합니다. 그 한마디도 빼려면 ~/.codex/AGENTS.md에 적어 둡니다. 터미널 커밋을 붙이려면 저장소마다 한 번 sh tools/hooks/install_git_hook.sh.

claude.ai · ChatGPT설치 없이 커넥터로 같은 URL을 넣습니다. 호스팅 서버에서만 되고, git 정보(브랜치·커밋 연결)는 붙지 않습니다.
에이전트를 섞어 써도같은 기록을 봅니다. 스레드 연결은 폴더마다 하나라, 같은 폴더에서 동시에 돌리지만 않으면 됩니다.
지울 때로컬은 sqlite 파일 하나를 지우면 끝입니다. 서버는 신청 페이지에 적힌 대로 요청합니다.
